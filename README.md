# Frutty Cream Web

Sitio web empresarial y responsivo para Frutty Cream, heladeria ubicada en Mocoa, Putumayo. El proyecto fue desarrollado como actividad ABP usando HTML5, CSS3, JavaScript y Bootstrap 5.

## Modulo de Junior

Junior, identificado en Git como `NORMAN-ITP`, trabajo las funcionalidades relacionadas con:

- Pagina de promociones.
- Promociones visuales con imagenes.
- Favoritos guardados con LocalStorage.
- Sabor favorito guardado con LocalStorage.
- Apoyo en estilos responsive de promociones y preferencias.

## Archivos Del Modulo

- `pages/Promociones.html`
- `pages/Productos.html`
- `js/storage.js`
- `css/style.css`
- `img/Prom1.webp`
- `img/prom2.jpg`
- `img/prom3.jpg`

## Funcionalidades

- El usuario puede marcar productos y promociones como favoritos.
- Los favoritos se guardan en el navegador con `localStorage`.
- El usuario puede seleccionar su sabor favorito.
- El sabor favorito se mantiene guardado aunque se recargue la pagina.
- La pagina de promociones usa tarjetas visuales con imagenes.

## Requisito ABP Cubierto

Este modulo cumple el requisito de almacenamiento local de preferencias e interactividad con JavaScript.
